# product-shot 功能讲解

一句话：把一张**白底产品图**，自动生成多套可交付的商品图 —— 不同**场景** × 不同**角度** × 不同**排版**，产品文字像素级保真。

---

## 一、主要功能

### 1. 白底抠图（不依赖第三方模型）
用纯算法把白底产品图抠成透明底（RGBA），并做**反预乘去白边**，保证深色背景上不出现白晕。产品主体 100% 来自原图，**绝不重画产品或丝印文字**。

### 2. 预乘放大 + 边缘安全锐化
产品图 2 倍放大（800px 源图 → 1600px 成品可用），用"预乘 alpha"方式放大避免白边碎点，锐化只作用于不透明区、避开软边带，丝印文字放大后仍锐利。

### 3. 空场景生成（AI 只画背景，双通道）
通过 bundle 自带的 `generate_scene` 工具调用 Agnes 生图 API，生成**不含产品的空背景**（场景）。也可以用 `assets/scenes/` 里已预置的 6 张背景，无需联网。

Agnes 是**免费通道**，排队过久时工具会返回 `queue_stalled` 信号，skill 会停下问用户是否切换**付费 fallback 通道**（OpenAI 兼容，默认关闭，报价按 `fallbackPricePerImageRMB`）。用户同意才走付费，不同意继续等免费或改用预置背景。

### 3.5 商品短视频（免费链 → 多平台付费报价）

`generate_video` 把成品图变成可投放的短视频：文生视频，或把质检通过的 `hero` 成品图作为**首帧**做图生视频（产品外观不变，只让画面动起来）；也可传 1–5 张参考图做多角度。默认 720P、5 秒、`16:9`，成品落在 `outputDir/videos/`。

免费通道不是只有 Agnes 一家，而是一条**免费链**（`freeChain`，默认 `agnes,zhipu,dashscope,ark`）：Agnes 视频、智谱 CogVideoX-Flash（官方 0 元）、阿里百炼万相（新用户送秒数）、火山方舟 Seedance（每模型送 token）。某家额度用尽或队列满，会自动记进 `tried` 并换下一家；该家的付费档同时进入报价候选。

免费链累计排队超过 `videoQueueTimeoutMs`（默认 10 分钟，在可用通道间均分）→ 返回 `queue_stalled`，带每家尝试记录 `tried`、**全平台即时报价 `quotes`**（provider、模型、预估 RMB、画质优劣、是否已配 key、文档链接）、以及可续查的 `video_id`。skill 停下把报价整理成对比表让用户自己挑：继续等（`video_status` 续查，任务不丢）或 `channel: "paid"` + `provider: "<选中的>"`。**用户不点头不扣费。**

各通道参考价（2026-11-26，以官网为准）：智谱 CogVideoX-Flash 免费 / CogVideoX-3 ≈ ¥1 条；百炼万相 2.1 turbo ≈ ¥0.24/秒；方舟 Seedance pro-fast ≈ ¥0.20/秒；硅基流动 MiniMax-H3 ≈ ¥0.50/秒（带音轨、无免费额度）。

自定义付费通道（旧 `fallback*` 配置，OpenAI 兼容风格，默认关闭）：`fallbackVideoModel` + `fallbackBaseURL` + key，可选 `fallbackVideoEndpoint` / `fallbackVideoStatusEndpoint` / `fallbackPricePerVideoRMB`。

> 视频里的丝印/包装文字会糊、会漂移；文字仍以静态成品图和后期字幕为准。

### 4. 多场景 × 多角度 × 多排版合成
- **场景**（6 个）：`E` 暗黑金属 / `F` 浅色影棚 / `G` 暖石材 / `H` 暗台面 / `I` 浅台面 / `J` 暗斜光带
- **角度**（5 个）：`vertical` 竖放 / `flat` 横放 / `diag` 斜放 / `tilt` 斜立 / `lie` 躺放
- **排版**（2 个）：`hero` 产品占满无文字（类样品图）/ `poster` 产品右置 + 左栏文案

合成时自动加**方向光（relight）、地面阴影、接触影**，让产品"落"在场景里，光影匹配控制在 5% 以内。

### 5. 排版 + 第二遍锐化
文案（主标/副标/适配机型/徽章）全部由 Pillow 真实渲染（**绝不交给 AI 生成文字**，这是文字清晰的第二道保险）；成品再整体锐化一遍。

### 6. 质检质量门（verify.py 会挡）
成品交付前自动断言三道关：matte 软边占比 ≤2%、透明区 RGB 均值 ≤0.15、成品 1600×1600 且非空白。不过关就非零退出，避免带着白边交付。

### 7. 预期效果图分区
用户把想要的参考效果图丢进 `effectsDir`（默认 `product-shot-effects/`），skill 开工前会先读这里，按用户放的效果图风格去生成。

### 8. 自包含
生图逻辑（`generate_scene` 工具，免费 Agnes + 付费 fallback 双通道）就打包在 bundle 内，**不依赖 dsh-agnes-tools 或其他生图插件**；只跟 dsh-agnes-tools 共用同一个 key 约定（`AGNES_API_KEY`），用户填一次即可两用；视频还可在插件配置里另填 `ZHIPU_API_KEY` / `DASHSCOPE_API_KEY` / `ARK_API_KEY` / `SILICONFLOW_API_KEY` 来扩展免费链和付费候选。

## 二、目录结构 & 每个文件/文件夹的作用

```
product-shot/
├── index.js                ← 插件入口：注册 generate_scene 工具 + 注册 product-shot 技能
├── package.json            ← 包描述：名称/版本/依赖/DSH bundle 声明
├── cordis.patch.yml        ← 插件行 + 默认配置（apiKeyRef/baseURL/effectsDir 等）
├── SKILL.md                ← 给 agent 看的技能说明书（铁律 + 工作流 + 参数）
├── README.md               ← 给人类看的自述
├── icon.svg                ← 插件图标
├── locale/
│   ├── zh.json             ← 中文显示元数据（标题/描述/详情）
│   └── en.json             ← 英文显示元数据
├── scripts/                ← 六个管线脚本（全流程核心）
│   ├── preflight.py        ← 预检：分辨率/贴边/白底，不合格直接拒绝
│   ├── key.py              ← 抠图：白底 → RGBA 透明 + 反预乘去白边
│   ├── upscale.py          ← 2x 预乘放大 + 边缘安全锐化
│   ├── render.py           ← 合成：方向光/阴影 + 四角度渲染器，参数来自 references
│   ├── typography.py       ← 排版 + 第二遍锐化（hero 只锐化，poster 加文案）
│   └── verify.py           ← 质检：三道质量门
├── references/             ← 参数外置（改参数不用改代码）
│   ├── scenes.json         ← 6 场景的 relight + 各角度已验证参数
│   ├── angles.json         ← 5 角度族 → 渲染器映射
│   └── layouts.json        ← 文案/配色(3套)/排版坐标/锐化参数
├── assets/
│   ├── scenes/             ← 6 张预置空背景（bg_a~bg_j，离线可用）
│   └── effects/            ← 3 张自带风格参考（暗黑金属/浅色影棚/产品样图）
└── docs/
    ├── 功能讲解.md         ← 本文档
    └── 如何申请并接入API_Key.md  ← 给最终用户的 key 申请+接入教程
```

### 逐文件说明

**根目录文件**

| 文件 | 作用 |
|---|---|
| `index.js` | 插件入口。干两件事：① `apply()` 里 `ctx.tools.register` 注册 `generate_scene` 生图工具（走 Agnes，key 解析顺序 apiKey → 凭据 → 环境变量）；② `ctx.skills.register` 注册 `product-shot` 技能，并把资源根指向本目录，让脚本/资产可被解析。 |
| `package.json` | 包元数据；`"dsh":{"bundle":{"patch":"./cordis.patch.yml"}}` 声明这是一个 DSH bundle。 |
| `cordis.patch.yml` | 插件插入行 + 默认配置值（`apiKeyRef: AGNES_API_KEY`、`baseURL`、`imageModel`、`outputDir`、`effectsDir`）。 |
| `SKILL.md` | 给 agent 的技能正文：铁律、工作流、参数速查、质量门、已知限制。agent 做产品图时先读它。 |
| `README.md` | 给人看的功能/安装/配置说明。 |
| `icon.svg` | 插件列表里的图标。 |
| `locale/*.json` | 插件在 DSH 界面显示的名称/描述（中英）。 |

**scripts/（六个脚本，按管线顺序）**

| 脚本 | 输入 → 输出 | 作用 |
|---|---|---|
| `preflight.py` | 产品图 → JSON 报告 | 预检：分辨率 ≥1200px（800px 硬拒）、不贴边、白底、无原投影，不合格非零退出 |
| `key.py` | 产品图 → `product_rgba.png` | 白底抠图：`d=255-min(RGB)` 阈值 7 → 中心连通域 → 补洞 → 腐蚀 1px → 0.7 羽化 → 反预乘去白边 |
| `upscale.py` | `product_rgba.png` → `product_2x.png` | 预乘 alpha 2x 放大 + 不透明区锐化（避开软边） |
| `render.py` | `product_2x.png` + 场景/角度参数 → 合成图 | 方向光 relight（≤5%）+ 地面阴影 + 接触影 + 竖放/横放/斜立/躺放四渲染器 |
| `typography.py` | 合成图 → 成品 | 第二遍锐化 + 排版（hero 只锐化；poster 加主标/副标/机型/徽章文案） |
| `verify.py` | matte + 成品 → 质检报告 | 三道质量门，不过关非零退出 |

**references/（参数外置，改这里不用改代码）**

| 文件 | 内容 |
|---|---|
| `scenes.json` | 6 个场景（E/F/G/H/I/J）各自的 relight 参数 + 五个角度下的坐标/缩放/阴影参数 |
| `angles.json` | 5 个角度族（vertical/flat/diag/tilt/lie）→ 渲染器映射 |
| `layouts.json` | 文案文案、3 套配色（dark/light/stone）、hero/poster 排版坐标、锐化参数 |

**assets/**

| 文件夹 | 内容 |
|---|---|
| `scenes/` | 6 张预置空背景（`bg_a_darkmetal` 暗黑金属、`bg_b_lightstudio` 浅影棚、`bg_c_warmstone` 暖石材、`bg_h_darktable` 暗台面、`bg_i_lighttable` 浅台面、`bg_j_darkstreak` 暗斜光带）。离线也能出图。 |
| `effects/` | 3 张自带风格参考（`ref_dark_metal` 暗黑金属、`ref_light_studio` 浅影棚、`demo_product` 产品样图）。 |

**docs/**

| 文件 | 作用 |
|---|---|
| `功能讲解.md` | 本文档 |
| `如何申请并接入API_Key.md` | 给最终用户的 Agnes key 申请 + 接入教程（随 bundle 分发） |

## 三、一次完整流程（管线串联）

```
产品图
  → preflight.py  预检（不合格拒绝）
  → key.py        抠图成透明底
  → upscale.py    2x 放大 + 锐化
  → generate_scene 工具（免费 Agnes；排队超时→问用户→付费 fallback；或复用 assets/scenes/）  生成空背景
  → render.py     合成（方向光 + 阴影 + 角度）
  → typography.py 排版 + 第二遍锐化
  → verify.py     质检（不过关非零退出）
成品图（1600×1600）
  → generate_video（可选：hero 成品图当首帧；免费排队超 10 分钟→问用户→付费 fallback）
成品短视频（mp4）
```

## 四、可配置项（插件配置）

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `apiKey` | 空 | 直接填 Agnes key（优先级最高） |
| `apiKeyRef` | `AGNES_API_KEY` | 从 DSH 凭据读取的 key 引用名（与 dsh-agnes-tools 共用） |
| `baseURL` | `https://api.agnes-ai.cn/v1` | Agnes 节点；**国际 key 要改成 `https://apihub.agnes-ai.com/v1`** |
| `imageModel` | `agnes-image-2.5-flash` | 生图模型 |
| `outputDir` | `product-shot-output` | 成品输出目录（绝对路径，或相对 DSH 进程 cwd） |
| `effectsDir` | `product-shot-effects` | **预期效果图分区**：用户放参考效果图的地方 |
| `queueTimeoutMs` | `300000` | 免费通道排队多久算"卡住"（默认 5 分钟） |
| `fallbackEnabled` | `false` | 是否启用付费 fallback 通道 |
| `fallbackName` | `SiliconFlow` | 付费通道显示名（报价时用） |
| `fallbackBaseURL` | 空 | 付费通道 OpenAI 兼容接口地址（如 `https://api.siliconflow.cn/v1`） |
| `fallbackImageModel` | 空 | 付费通道生图模型（如 `black-forest-labs/FLUX.1-schnell`） |
| `fallbackApiKey` | 空 | 付费通道 key 直填（优先级最高） |
| `fallbackApiKeyRef` | 空 | 付费通道 key 的 DSH 凭据引用名 |
| `fallbackPricePerImageRMB` | `0.05` | 单张报价（人民币，用于 queue_stalled 时告知用户） |
| `videoModel` | `agnes-video-2.5-flash` | 免费视频模型（720P） |
| `videoQueueTimeoutMs` | `600000` | 免费链排队多久算“卡住”（默认 10 分钟，在可用通道间均分） |
| `videoPollIntervalMs` | `8000` | 视频任务轮询间隔 |
| `videoStatusWaitMs` | `120000` | `video_status` 一次最多等多久 |
| `freeChain` | `agnes,zhipu,dashscope,ark` | 免费链顺序（没配 key 的家自动跳过） |
| `zhipuApiKeyRef` / `zhipuVideoModel` / `zhipuPaidVideoModel` | `ZHIPU_API_KEY` / `cogvideox-flash` / `cogvideox-3` | 智谱：Flash 免费，付费 CogVideoX-3 |
| `dashscopeApiKeyRef` / `dashscopeT2VModel` / `dashscopeI2VModel` | `DASHSCOPE_API_KEY` / `wanx2.1-t2v-turbo` / `wanx2.1-i2v-turbo` | 阿里百炼万相 |
| `arkApiKeyRef` / `arkVideoModel` | `ARK_API_KEY` / `doubao-seedance-1-0-pro-fast-251015` | 火山方舟 Seedance |
| `siliconflowApiKeyRef` / `siliconflowVideoModel` | `SILICONFLOW_API_KEY` / `MiniMaxAI/MiniMax-H3` | 硅基流动（无免费额度） |
| `priceZhipuPerVideo` / `priceDashscopePerSecond` / `priceArkPerSecond` / `priceSiliconflowPerSecond` | `1` / `0.24` / `0.2` / `0.5` | 报价单价（RMB） |
| `fallbackVideoModel` | 空 | 自定义付费视频通道模型（留空 = 不用） |
| `fallbackVideoEndpoint` | 空 | 自定义付费提交端点（默认 `${fallbackBaseURL}/videos/generations`） |
| `fallbackVideoStatusEndpoint` | 空 | 自定义付费状态端点：含 `{id}` 用 GET，否则 POST `{requestId}` |
| `fallbackPricePerVideoRMB` | `0.5` | 自定义付费通道单条报价（RMB） |

## 五、已知限制（如实告知）

- 几何合成能保证产品文字 **100% 原样**；代价是"躺放"在近正面源图上会偏薄（源图没有侧壁厚度）。
- 要"有厚度的躺放"可选 AI 重绘，但会改动产品外观（机身/模组/丝印）——默认不做。
- 字体默认依赖 Windows 微软雅黑（`msyh.ttc`/`msyhbd.ttc`/`simhei.ttf`），其他系统需改 `references/layouts.json` 的 `fonts`。
- Python 依赖 numpy + Pillow（DSH 自带的 python.exe 已含，无需 pip install）。
- 免费视频队列经常满（`video_queue_full`）：默认要重试到 10 分钟预算才返回 `queue_stalled`，之后靠 `video_status` 续查或改付费通道。
- 视频里的丝印/包装文字会糊、会漂移，文字仍以静态成品图和后期字幕为准。
